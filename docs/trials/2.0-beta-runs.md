## Что изменилось после alpha

Коммиты `d545c39` (спайк S0-OC), `2a10c68` (пресет `opencode`), `ce19682` и `4f950ea` (адаптер OpenCode), V2
(рецепты, версия, CI). Затронутое в общих скриптах:

- `engine-config.py` — новый пресет `opencode`, строка OpenCode в таблице сред, `installed_clis()`: на Kimi,
  Codex и Claude Code разрешение ролей не меняется (тесты шага 0b и эталоны F1 зелёные);
- `run-engine.sh` — новая ветка разбора JSON OpenCode, срабатывает только на строках с `sessionID`
  (фикстуры Kimi, Codex и cursor разбираются как раньше);
- `supertick-setup.py` — модели OpenCode из `opencode models`, OpenCode может вести;
- `lead-probe.py` — запуск OpenCode; для всех сред ведущий запускается с `PWD` стенда.

Поэтому прогоны alpha не повторялись; регрессию держит полный набор тестов перед V2.
