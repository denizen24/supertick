# Сборка и раскладка репозитория (ветка universal)

Одна кодовая база на несколько сред (121-567, D23). Править нужно исходники, а не результат сборки.

| Что | Где |
|---|---|
| общие скрипты и их тесты | `core/scripts/` (`core/scripts/tests/`) |
| навыки, агенты, манифест плагина, README для Claude Code | `hosts/claude-code/` |
| что и куда собирается | `hosts/<хост>/build.json` |
| генератор | `tools/build-host.py` |
| результат для Claude Code (лежит в git для маркетплейса) | `plugins/supertick/` — руками не правится |

## Как работать

```bash
# правка в core/ или hosts/claude-code/, затем
python3 tools/build-host.py claude-code            # привести plugins/supertick/ к сборке
python3 tools/build-host.py claude-code --check    # только проверить (то же делает CI)
```

Сборка не переписывает совпавшие файлы, удаляет лишние, берёт бит исполнения у источника.
`--out <каталог>` собирает в другое место, но только в пустое.

## Три правила, которые держат тесты (`tools/tests/test_build_host.py`)

1. **Тождество с 1.1.1.** Пока осознанных правок нет, сборка для Claude Code побайтно равна 1.1.1:
   хеши и бит x по `tools/tests/snapshots/plugin-1.1.1.manifest`. Осознанная правка файла плагина
   записывается строкой в `tools/tests/snapshots/plugin-1.1.1.changes` (путь и причина) и в `CHANGELOG.md`.
   Запись, которая с 1.1.1 уже не расходится, — тоже ошибка.
2. **Плагин в git равен свежей сборке.** Правка `plugins/supertick/` в обход исходников не проходит CI.
3. **`core/` не знает Claude Code.** Нет `CLAUDE_*`, `~/.claude`, каталога `.claude/`, имён его
   инструментов и типов агентов. Исключения — в `tools/core-neutrality.json` с точным числом строк на
   файл и шаблон. Сейчас это комментарии, докстринги и фикстуры 1.1.1; переписываются нейтрально в P1/P2,
   счётчики идут к нулю. `CLAUDE_*` и `~/.claude` исключений не имеют вовсе.

## Новый хост

Каталог `hosts/<хост>/` с `build.json` (`output` и список `include` из пар `from` → `to`, пути от
корня репозитория, без `..`). Два источника на один выходной файл — ошибка сборки.
