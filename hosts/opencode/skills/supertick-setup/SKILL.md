# supertick: подключение (OpenCode)

Корень набора — `$SUPERTICK_ROOT` или соседний навык `supertick-team-feature` (одной командой, подставив вместо
`<SKILL_DIR>` путь из строки «Base directory for this skill»: `cd "${SUPERTICK_ROOT:-<SKILL_DIR>/../supertick-team-feature}" && pwd`);
`<S>` — `<корень>/scripts`.

1. Что установлено (каждый CLI пробуется одним коротким вызовом; у `bash` — `timeout: 300000`):

   ```bash
   python3 <S>/supertick-setup.py discover --host opencode --json
   ```

2. Вопросы — текстом, по одному, с нумерованными вариантами (не больше четырёх; остальное — «другое»),
   ответ пользователя — следующий ход:
   - **ведущий** — среды с `lead_capable` и состоянием `responds`; пометка по `lead_probes` из
     вывода `discover` (та же среда и модель): «проверена как ведущий <дата>», «проба ведущего <дата>:
     failed: <проверка>» или «не проверена»; «нужен перезапуск», если это не opencode;
   - **состав команды** — «всё на модели ведущего» (родные исполнители OpenCode); «код и ревью на разных
     моделях» (при двух и более источниках из `sources`); «по группам ролей» — по вопросу на группу:
     кодеры, рецензент, архитекторы и техлид, исследователи, проверяющие. Модели OpenCode — из `models`
     вывода `discover`; у Zen оплата за токены, бесплатные (`*-free`) стоят первыми;
   - **второе мнение** — другая модель или «выключено» (при одном источнике не спрашивать);
   - **имя профиля** (по умолчанию `default`).
3. Ответы — файлом `~/.config/supertick/answers.json` (формат — шапка `supertick-setup.py`), затем
   таблица без записи:

   ```bash
   python3 <S>/supertick-setup.py plan --answers <файл ответов>
   ```

   Покажи таблицу пользователю, `ОШИБКА:` — вернись к вопросам. Подтвердил — запись:

   ```bash
   python3 <S>/supertick-setup.py apply --answers <файл ответов>
   ```

4. Строку `запуск:` из вывода — пользователю, если ведущий не текущая сессия.
5. **Проба ведущего.** В таблице есть строка «⚙️ ведущий не проверен пробой» — предложи её («проверить
   сейчас (15–20 минут вызовов модели)» / «позже»). Согласился — запусти и дождись в этом же ходе
   (на переднем плане, у `bash` — `timeout: 3600000`):

   ```bash
   python3 <S>/supertick-setup.py lead-probe <профиль>
   ```

   Покажи пользователю строку итога (`passed` или `failed: <проверка>`) и строки с ✗. Итог уже записан в
   профиль; провал ничего не запрещает, это предупреждение, что модель может не удержать протокол.

В `opencode run` вопросы задать нельзя: скажи пользователю запустить `python3 <S>/supertick-setup.py setup`
в терминале.
