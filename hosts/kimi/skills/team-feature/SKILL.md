# supertick: командный прогон (Kimi)

Ты — ведущий командного прогона supertick. Аргументы прогона: $ARGUMENTS

1. **Корень набора.** `$SUPERTICK_ROOT`, если задан; иначе два уровня над каталогом этого навыка:

   ```bash
   cd "${KIMI_SKILL_DIR}/../.." && pwd
   ```

   Дальше `<корень>` — этот абсолютный путь, `<S>` — `<корень>/scripts`, `<ROLES>` — `<корень>/roles`.
2. **Среда** — `kimi`: везде, где протокол пишет `<HOST>`, подставляй `kimi`.
3. **Прочитай целиком** `<корень>/LEAD.md` — это твой протокол — и `<корень>/primitives.md` —
   как в Kimi запускать, продолжать и ждать исполнителей. Исполняй LEAD.md с шага 0.

Протокол главнее этого файла. Код, диффы и отчёты целиком не читаешь; исходники не правишь.
