# supertick: подключение (Kimi)

Корень набора — `$SUPERTICK_ROOT` или два уровня над этим навыком (одной командой: `cd "${SUPERTICK_ROOT:-${KIMI_SKILL_DIR}/../..}" && pwd`);
`<S>` — `<корень>/scripts`.

1. Что установлено (каждый CLI пробуется одним коротким вызовом):

   ```bash
   python3 <S>/supertick-setup.py discover --host kimi --json
   ```

2. Вопросы — `AskUserQuestion`, не больше четырёх вариантов на вопрос (остальное через «Другое»):
   - **ведущий** — среды с `lead_capable` и состоянием `responds`; пометка по `lead_probes` из
     вывода `discover` (та же среда и модель): «проверена как ведущий <дата>», «проба ведущего <дата>:
     failed: <проверка>» или «не проверена»; «нужен перезапуск», если это не kimi;
   - **состав команды** — «всё на модели ведущего»; «код и ревью на разных моделях» (при двух и
     более источниках из `sources`); «по группам ролей» — по вопросу на группу: кодеры, рецензент,
     архитекторы и техлид, исследователи, проверяющие;
   - **второе мнение** — другая модель или «выключено» (при одном источнике не спрашивать);
   - **имя профиля** (по умолчанию `default`).
3. Ответы — файлом `~/.config/supertick/answers.json` (формат — шапка `supertick-setup.py`), затем
   таблица без записи:

   ```bash
   python3 <S>/supertick-setup.py plan --answers <файл ответов>
   ```

   Покажи таблицу пользователю, `ОШИБКА:` — вернись к вопросам. Подтвердил — запись:

   ```bash
   python3 <S>/supertick-setup.py apply --answers <файл ответов>
   ```

4. Строку `запуск:` из вывода — пользователю, если ведущий не текущая сессия.
5. **Проба ведущего.** В таблице есть строка «⚙️ ведущий не проверен пробой» — предложи её
   (`AskUserQuestion`: «проверить сейчас (несколько минут вызовов модели)» / «позже»). Проба запускает
   ещё один Kimi на модели ведущего с крошечной задачей на мок-движках, поэтому только в фоне:

   ```bash
   python3 <S>/supertick-setup.py lead-probe <профиль>
   ```

   `Bash(..., run_in_background=true)`, конец хода; разбудит её конец. Покажи пользователю строку итога
   (`passed` или `failed: <проверка>`) и строки с ✗. Итог уже записан в профиль; провал ничего не
   запрещает, это предупреждение, что модель может не удержать протокол.

В режиме `kimi -p` вопросы задать нельзя: скажи пользователю запустить
`python3 <S>/supertick-setup.py setup` в терминале.
