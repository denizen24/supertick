# supertick: подключение (Codex)

Корень набора — `$SUPERTICK_ROOT` или два уровня над каталогом этого файла SKILL.md (одной командой, подставив
его абсолютный путь вместо `<SKILL_DIR>`: `cd "${SUPERTICK_ROOT:-<SKILL_DIR>/../..}" && pwd`); `<S>` — `<корень>/scripts`.

1. Что установлено (каждый CLI пробуется одним коротким вызовом):

   ```bash
   python3 <S>/supertick-setup.py discover --host codex --json
   ```

2. Вопросы — текстом, по одному, с нумерованными вариантами (не больше четырёх; остальное — «другое»),
   ответ пользователя — следующий ход:
   - **ведущий** — среды с `lead_capable` и состоянием `responds`; пометка по `lead_probes` из
     вывода `discover` (та же среда и модель): «проверена как ведущий <дата>», «проба ведущего <дата>:
     failed: <проверка>» или «не проверена»; «нужен перезапуск», если это не codex;
   - **состав команды** — «всё на модели ведущего» (роли пойдут движком codex на этой модели); «код и
     ревью на разных моделях» (при двух и более источниках из `sources`); «по группам ролей» — по вопросу
     на группу: кодеры, рецензент, архитекторы и техлид, исследователи, проверяющие;
   - **второе мнение** — другая модель или «выключено» (при одном источнике не спрашивать);
   - **имя профиля** (по умолчанию `default`).
3. Ответы — файлом `~/.config/supertick/answers.json` (формат — шапка `supertick-setup.py`), затем
   таблица без записи:

   ```bash
   python3 <S>/supertick-setup.py plan --answers <файл ответов>
   ```

   Покажи таблицу пользователю, `ОШИБКА:` — вернись к вопросам. Подтвердил — запись:

   ```bash
   python3 <S>/supertick-setup.py apply --answers <файл ответов>
   ```

4. Строку `запуск:` из вывода — пользователю, если ведущий не текущая сессия. Ведущий Codex запускается
   без песочницы (`--sandbox danger-full-access`): иначе исполнители из его shell не стартуют.
5. **Проба ведущего.** В таблице есть строка «⚙️ ведущий не проверен пробой» — предложи её («проверить
   сейчас (15–20 минут вызовов модели)» / «позже»). Согласился — запусти и дождись в этом же ходе
   (на переднем плане; вернулся id сессии — `write_stdin` с пустым вводом и ожиданием 300000 мс до выхода):

   ```bash
   python3 <S>/supertick-setup.py lead-probe <профиль>
   ```

   Покажи пользователю строку итога (`passed` или `failed: <проверка>`) и строки с ✗. Итог уже записан в
   профиль; провал ничего не запрещает, это предупреждение, что модель может не удержать протокол.

В `codex exec` вопросы задать нельзя: скажи пользователю запустить `python3 <S>/supertick-setup.py setup`
в терминале.
