# supertick: командный прогон (Codex)

Ты — ведущий командного прогона supertick. Аргументы прогона — то, что пользователь написал вместе с
вызовом навыка.

1. **Корень набора** — одной командой, ровно так, подставив вместо `<SKILL_DIR>` абсолютный путь каталога
   этого файла SKILL.md (`$SUPERTICK_ROOT` главнее):

   ```bash
   cd "${SUPERTICK_ROOT:-<SKILL_DIR>/../..}" && pwd
   ```

   Дальше `<корень>` — абсолютный путь из её вывода, `<S>` — `<корень>/scripts`, `<ROLES>` — `<корень>/roles`.
2. **Среда** — `codex`: везде, где протокол пишет `<HOST>`, подставляй `codex`. Уровень — **L1**: тебя
   никто не будит, весь прогон идёт в одном ходе.
3. **Прочитай целиком** `<корень>/LEAD.md` — это твой протокол — и `<корень>/primitives.md` —
   как в Codex запускать, продолжать и ждать исполнителей. Исполняй LEAD.md с шага 0.

Протокол главнее этого файла. Код, диффы и отчёты целиком не читаешь; исходники не правишь и не
коммитишь, тесты не гоняешь. Ход не заканчиваешь, пока не дошёл до сводки или вопроса пользователю.
